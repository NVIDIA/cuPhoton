A.2 Command line

cuphoton --help lists the command groups, one per module:

cuphoton

GPU-accelerated astronomy and imaging tools.

Available groups:
  xdr  xDataReader: GPU-native FITS loading.
  xfit  xFit: Batched nonlinear least-squares fitting for astronomical models.
  ximage  Multi-frame image reconstruction and PSF calibration.
  xpois  Optimal image subtraction for astronomical images.
  xscan  Transient-candidate dataset, training, and review workflows.
  xrep  xRep (xReproject): WCS-aware astronomical image reprojection and stacking.
  xray  GPU-accelerated X-ray detector analysis tools.
  xlens  cuPhoton xLens: scientific monitoring and evidence review.
  xbeam  xBeam: Time-series correlation and VLBI visibility generation.

Use 'cuphoton GROUP --help' for group help.

cuphoton <group> --help lists a group’s commands, and cuphoton <group> help <command> prints one command’s options with their defaults. The command-line index describes every group. Chapter 3 explains the flags that the groups share.

A.3 Python API

Each function’s docstring documents its arguments, defaults and return fields. Print a signature with inspect, or the whole docstring with help:

import inspect
from cuphoton.xrep import reproject_masked_array

print(inspect.signature(reproject_masked_array))
(image: 'np.ndarray', variance: 'np.ndarray', mask: 'np.ndarray', spec: 'ReprojectionSpec', *, backend: 'str | None' = None, prepared: 'PreparedReprojection | None' = None, variance_fill_value: 'float' = nan) -> 'MaskedReprojectionResult'

Each package lists its public names in __all__:

import importlib

print("package          public names")
for name in ("core", "xdr", "xrep", "ximage", "xpois", "xfit", "xscan", "xray", "xbeam", "xlens"):
    package = importlib.import_module(f"cuphoton.{name}")
    print(f"cuphoton.{name:7s} {len(package.__all__):12d}")

xScan and xRay export only their version at the top level. They are command-line tools first. Their reference pages show the submodules to import from, such as cuphoton.xscan.fits_inference and cuphoton.xray.detector_artifacts. Core’s shared code also lives in submodules:

  • cuphoton.core.fits_io: the FITS reader and its receipts.
  • cuphoton.core.arrays: helpers that serve NumPy and CuPy arrays with one code path.
  • cuphoton.core.cli: the command-line framework.
  • cuphoton.core.executors: Dragon and MPI execution.

A.5 Getting help

cuPhoton has best-effort community support through its GitHub repository. Its support policy gives the details.

  1. Search the GitHub issues for your problem.
  2. If no issue matches, open a bug report with a minimal reproducer. Include the following:
    • the output of cuphoton --version
    • the cuPhoton commit, Python version, operating system and installed extras
    • the command line and the shapes of your inputs
    • for a GPU problem, the GPU model, driver, CUDA runtime, the backend from summary.json, and whether the CPU profile works
  3. Open a feature request for a new workflow or data contract, or a pull request for a concrete fix.

Remove credentials, private paths and proprietary data from what you post. Do not report security problems on GitHub. Follow the security policy instead.
